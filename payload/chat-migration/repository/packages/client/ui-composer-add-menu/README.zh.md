# `@deepseek-ai/dsh-composer-add-menu`

[English](README.md) | 中文

Web 输入框的原生单层添加目录。它取代临时的 Profile 外置包，占用 `conversation.input.add`，但不另造一套命令、附件或引用协议；这是产品基础交互，不是可开关的目录插件。

工作对话复用对话所有者的图片校验链路和工作区文件／文件夹选择器。**命令、插件与技能**分组先展示当前会话的 Host 官方命令目录，再展示剩余由斜杠来源提供的 Skill。选中只会在文本框选区插入 `/name `，不会立即执行。官方命令与 Skill 同名时，官方命令优先。纯聊天复用同一个加号，但只显示上传：图片继续走持久图片链路；不超过 256 KB 的文本、Markdown、CSV／JSON 和常见代码文件会进入草稿并随消息保存。相邻的「联网搜索」胶囊是当前聊天的真实开关：蓝色表示开启，灰色表示关闭；关闭后会在工具执行前同时拦截公开网页搜索与网页读取。聊天不会因此获得工作区引用、命令目录、Skill 或文件系统权限。

所有 Skill 行统一复用现有 `IconSkillOutline16`，官方命令复用现有插件图标。选中、点击外部、按 Escape 或输入框禁用时会关闭菜单，同时保留原生文本框焦点行为。

## 模型体验

### 本地草稿插入

#### 模型看到什么

选择时模型看不到任何内容。选择一行只会修改本地 `/name` 草稿；只有用户之后通过既有输入框发送时，对应命令或 Skill 才会进入模型链路。

#### Token 影响

打开菜单和选择条目都不消耗模型 Token。之后发送的消耗与用户手动输入同一个斜杠条目完全相同。

#### KV Cache 影响

菜单不改变 system 上下文或模型请求，因此不会产生独立的缓存影响。

## 已知限制与延后工作

- 菜单只展示 `ui-conversation` 提供的实时目录；来源没有提供描述时，不自行编造。
- 当前会话或模型关闭对应原生能力时，图片和工作区操作仍然不可用。
